GET STARTED

Up and running
in three steps.

Prowl is a Forge mod for Minecraft 1.8.9. Add the JAR to the mods folder for the Forge profile you use.

  1. 01

    Use Forge 1.8.9

    Launch a Minecraft 1.8.9 profile with Forge installed.

  2. 02

    Drop in the JAR

    Put Prowl-Forge-1.8.9-Beta.jar in that profile’s mods folder.

  3. 03

    Restart the game

    Fully close and relaunch Minecraft so Forge loads Prowl.

!

PLEASE READ

Hypixel API key policy

Hypixel’s current policy says not to share API keys with third-party mods, including publicly available mods. Prowl v0.1.46 has a key field and sends the key to Hypixel, so do not enter a Hypixel key into this release. Read the official API policy and see the lookup documentation for implementation details. The download contains no personal API keys.
